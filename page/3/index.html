内存马

发表于 2026-06-19 更新于 2026-08-09 分类于 Java安全
本文字数： 18k

基础

在学习tomcat内存马的时候会碰到各种context，其中StandardContext是最底层的context，也就是说对于Web应用的操作都会用到StandardContext，一个Web应用只会有一个StandardContext。ServletContext就是StandardContext的门面，他本质上操作的是StandardContext，ServletContext的实现类是ApplicationContext，ApplicationContextFacade是对ApplicationContext的封装。

tomcat内存马

这里我们是通过jsp上传tomcat内存马，也就是说要想上传内存马还得满足能够上传jsp文件这种情况，所以下面的学习都是在假设存在任意文件上传的情况下进行的。

Tomcat内存马的核心原理就是动态的将恶意组件Listener、Filter、Servlet啥的添加到正在运行的Tomcat服务器中，而ApplicationContextFacade是没有权限动态加载组建的，所以说还得想办法获取StandardContext。
